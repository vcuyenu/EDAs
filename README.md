# Exploratory Data Analysis Projects

A collection of exploratory data analysis (EDA) projects performed on various datasets using Python and common data science libraries.

These projects focus on:
- data cleaning
- statistical summaries
- visualization
- identifying trends and relationships
- extracting insights from structured data

---

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Common EDA Tasks Performed

- Data loading and inspection
- Handling missing values
- Checking data types and inconsistencies
- Summary statistics
- Correlation analysis
- Distribution analysis
- Feature comparison
- Outlier detection
- Data visualization

---

## Visualizations Used

- Histograms
- Box plots
- Scatter plots
- Line charts
- Correlation heatmaps
- Pair plots
- Count plots

---

## Objectives

The goal of these projects is to:
- improve practical data analysis skills
- understand dataset structure and behavior
- practice communicating insights visually
- build a stronger foundation for machine learning workflows
